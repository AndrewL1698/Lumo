# /extension — Chrome MV3 extension

Owner: **Naren**. Team rules: root `CLAUDE.md`. Design: `docs/architecture.md` §6. Contracts: `@parrot/shared`.

## What lives here
| Path | Does |
|---|---|
| `src/sw/index.ts` | Service worker. Holds the pairing token, queues events, does **all** network calls, registers content scripts per granted origin. |
| `src/content/index.ts` | Content script: walk text, match words, swap, hover cards. No `fetch` here. |
| `src/popup/popup.html`, `src/popup/index.ts` | Popup: pairing code entry, enable site (permission prompt), pause, toggle. |
| `src/messages.ts` | Typed messages between content script, popup and service worker. |
| `src/wordindex.json` | English form → lemmas. Placeholder now; generated by Karthik's `scripts/build-wordlist`. |
| `manifest.json` | MV3 manifest: `optional_host_permissions`, `toggle-parrot` command (Alt+Shift+P). |
| `build.mjs` | esbuild bundle into `extension/dist`. |

## Commands
- `npm run build -w extension` (or `npm run build:ext` from root), `npm run watch -w extension`, `npm run typecheck -w extension`
- Load: `chrome://extensions` → Developer mode → Load unpacked → `extension/dist`. After each rebuild click the reload icon on the card, then reload the page.
- There are no static content scripts. Enable a site from the popup first.

## Rules that bite here
- **No host access by default.** Sites are added one at a time from the popup via `chrome.permissions.request` (needs a user gesture), then `chrome.scripting.registerContentScripts`.
- **Hard never-list in code**, checked even if the user allowlists the site: email, chat, banking/payments/checkout, health/insurance, Docs/Canvas/Overleaf/GitHub, login and form pages.
- **The service worker does every fetch.** Content scripts message the SW. The token never enters the page.
- **No API keys** in the extension. TTS goes through `/api/tts`.
- **Never send** URLs, history or typed input, and never a page in one piece. Send only the sentences being translated (one per swapped word, plus whole sentences/paragraphs at high immersion, D-018), events, and title + domain. `articleKey = hash(domain + title)`.
- **Never block page load.** Swaps appear only after the `/api/translate` batch returns.
- **Only replace spans inside a single text node.** Skip matches that cross inline elements.
- Skip `a, button, input, textarea, select, code, pre, script, style, [contenteditable]` and anything inside `form`.
- Swap amount comes from the **immersion dial** (D-018, `src/swapBudget.ts`): below 20% it's today's rules (one swap per sentence, cap 25, `5 + solid`); higher steps allow more words per sentence (never adjacent), easier words, and whole Spanish sentences/paragraphs (`[data-parrot-block]`). All steps share one picker (`pickWords`, score-first, one swap per lemma) and one apply path (`applyOps`, several swaps per text node, right to left). A hover counts after 500 ms.
- *In progress (Andrew, Sat night, branch `andrew/immersion`):* D-018 touches `content/index.ts`, `content/hovercard.ts`, `sw/index.ts`, `messages.ts`, `popup/`. Ping Andrew before editing those.
- Event ids are client-made uuids (`crypto.randomUUID()`), so retries are safe.
- Only promise behaviour on the 2–3 demo sites. Don't chase layout bugs elsewhere.
